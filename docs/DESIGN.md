# 界面方向

现场照片为主要内容，管理页面以已存、已发、待核对状态组织。员工端只保留 Camera / Photos / Me；客户通过链接进入单记录页面。

- 蓝色 `#235EDB`：主操作与导航选择。
- 深蓝 `#19304B`：正文、标题。
- 背景 `#F3F6FA`，白色内容区域，边界 `#DCE4EF`。
- 绿色 `#19714B`：明确完成的文件校验；琥珀色只表示待处理。
- 网页使用 Trebuchet MS / Arial，原生 Android 使用系统 sans。
- 左侧导航用于桌面；窄屏顶部可横向滚动导航。照片保持独立视觉层级，客户页不显示后台设置。
- 空状态引导真实创建，不展示虚构业务数据。截图中的 QA 照片为测试脚本生成的人工样本。
- 水印直接覆盖照片内部，不增加画布边框；原图保持独立。

已检查桌面 1440px 和手机 390px 的管理首页、记录详情和客户页截图。Android UI 尚未完成真机视觉检查。
